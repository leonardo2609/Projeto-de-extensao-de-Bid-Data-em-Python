## 📖 Sobre o Projeto
Este projeto tem como objetivo realizar uma análise baseada em Big Data das ocorrências de acidentes na rodovia BR-101. O escopo geográfico abrange o trecho crítico entre os municípios do Rio de Janeiro, Niterói e São Gonçalo, analisando a série histórica durante o período de 2007 a 2026. Através do processamento de grandes volumes de dados, o estudo busca extrair inteligência para a melhoria do trânsito e a preservação de vidas.

## 🎯 Objetivos Principais
* **Identificação de Fatores**: Identificar os principais fatores causadores dos sinistros na rodovia.
* **Mitigação de Riscos**: Propor soluções viáveis, baseadas em evidências, para a mitigação de riscos no trânsito.
* **Mapeamento de Padrões**: Mapear os padrões de ocorrência espacial e temporal.
* **Análise de Sazonalidade**: Compreender a sazonalidade das colisões ao longo do ano.

## 🔬 Metodologia e Dados
A metodologia central da pesquisa consiste na correlação profunda de diversas variáveis presentes nos registros de trânsito. O projeto faz uso de bases de dados robustas, como os dados brutos da PRF (incluindo a base `datatran2007.csv`), processados inteiramente em Python. 

O cruzamento de dados foca nas seguintes variáveis espaço-temporais:
* **Data e Dia da semana**
* **Tipo de acidente**
* **Quilometragem e Localização exata**
